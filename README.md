# Panthoron website (2 November 2026)

One-page site for panthoron.com. Plain HTML, no build step.

## Files
- index.html: the whole page
- assets/: logo, photos, QR code, favicon

## To put it live on GitHub Pages
1. Create a GitHub account for Panthoron (sign up with hello@panthoron.com).
2. Create a public repository, for example "panthoron-site", and upload index.html and the assets folder.
3. In the repository: Settings > Pages > Source: "Deploy from a branch", branch "main", folder "/ (root)". Save.
4. The site appears at https://<account>.github.io/panthoron-site/ within a few minutes.

## To use panthoron.com
1. In Settings > Pages, enter panthoron.com as the custom domain and tick "Enforce HTTPS".
2. At the domain registrar, add four A records for panthoron.com: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153, and a CNAME record for www pointing to <account>.github.io.
3. Keep the existing MX (email) records unchanged, so @panthoron.com email keeps working.
